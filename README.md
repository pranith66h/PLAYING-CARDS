# Playing Cards Page

A responsive, modern playing cards display built with **HTML5**, **CSS3**, and **Flexbox**. This project was completed as part of freeCodeCamp's Responsive Web Design certification.


https://coruscating-kringle-24bfab.netlify.app## 

🚀 Live Demo

**[View Live Playing Cards →](https://coruscating-kringle-24bfab.netlify.app)**  
(Responsive on mobile, tablet & desktop)





## ✨ Features

- Clean card layout using **Flexbox**
- Horizontal centering + wrapping on smaller screens
- 20px spacing between cards (`gap: 20px`)
- Proper alignment: left at start, middle centered vertically, right at end
- Rotated right-side suit/rank for realistic card look
- Uses standard playing card suits: ♠ ♣ ♥ ♦
- Fully responsive (mobile-friendly)

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Flexbox layout, gradients, shadows, responsive design
- No JavaScript (pure CSS solution)

## 🎯 Project Goals (freeCodeCamp Requirements)

- Main element `#playing-cards` with Flexbox centering + wrap + 20px gap
- 3+ `.card` divs inside main
- Each card has `.left`, `.middle`, `.right` children
- `.card` uses `justify-content: space-between`
- `.left` → `align-self: flex-start`
- `.middle` → `align-self: center` + `flex-direction: column`
- `.right` → `align-self: flex-end` + rotated 180°

All user stories fulfilled and tests passed.
